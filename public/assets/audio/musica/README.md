# Lista de temas

Poné acá los MP3 con estos nombres (la lista está en `src/config.ts` → `audio.playlist`):

| Archivo | Banda |
| --- | --- |
| `champions-liga.mp3` | La Champions Liga |
| `18-kilates.mp3` | 18 Kilates |
| `marka-akme.mp3` | Marka Akme |
| `chili-fernandez.mp3` | El Chili Fernández |
| `nueva-escuela.mp3` | La Nueva Escuela |
| `la-planta.mp3` | La Planta |

- Los que falten simplemente no suenan; si no hay ninguno, vuelve la música de siempre.
- Para sumar más temas de una banda, agregá otra línea en `audio.playlist` con otro nombre de archivo.
- En `tema` va el nombre de la canción, que se muestra abajo a la izquierda cuando arranca.
- Ojo: el juego queda publicado en internet. Subir música con derechos de autor necesita permiso
  de los dueños (sello o banda); sin eso GitHub o la plataforma pueden bajar el sitio.
